# Convenience wrapper for environments that prefer requirements.txt.
#
# For a reproducible, fully-pinned environment use `uv sync` against the
# committed uv.lock. This file is an unpinned best-effort fallback.
#
# The canonical source of truth for constraints is pyproject.toml.
# Prefer the editable install with extras:
#
#     pip install -e .             # core only
#     pip install -e .[all]        # all optional features
#     pip install -e .[anthropic]  # specific feature
#
# Refer to README.md for the full extras matrix (anthropic, embeddings,
# ocr, documents, spreadsheets, presentations, gdrive, all). Lower-bound
# pins for individual packages live in pyproject.toml — the dependabot
# bumps that previously lived here have been propagated there.
-e .[all]
