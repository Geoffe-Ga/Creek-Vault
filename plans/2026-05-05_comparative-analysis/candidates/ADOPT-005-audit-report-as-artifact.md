# ADOPT-005: Audit Report As Primary Artifact (`creek state`)

**Verdict:** ADOPT
**Source system:** Graphify
**Affects:** Creek Vault data layer (CrawDad reads it as session-start context)
**Roadmap target:** v1
**Estimated complexity:** M
**Conflicts with non-negotiables?** none

## What it is

Graphify's `GRAPH_REPORT.md` is a structured markdown document produced after every extraction run. Sections:

1. **Summary** — node count, edge count, community count.
2. **Community Hubs** — Leiden-discovered logical components.
3. **God Nodes** — highest-degree concepts ranked by connection count.
4. **Surprising Connections** — inferred cross-domain edges ranked by composite score, code-to-paper edges ranked above code-to-code.
5. **Hyperedges** — group relations across communities.
6. **Suggested Questions** — 4–5 prompts the graph can uniquely answer.

Agents read it before tool calls via a `PreToolUse` hook. Humans read it to know what the system thinks the corpus is about. Cited from [README v5](https://github.com/safishamsi/graphify/blob/v5/README.md) and [graphify.net](https://graphify.net).

## Why it's interesting

Creek Vault has no equivalent. There is no single document an agent or human can read to answer "what's in the vault, what's growing, what's contradicting itself, what's surfacing this week." The five emergence report types each produce their own output in their own location; there's no unified state snapshot. This is the simplest single thing the project is behind on — and it's not philosophical, it's a missing artifact.

For CrawDad, the audit report becomes the session-start context: when the user pings the bot, the bot loads the latest audit report rather than re-traversing the vault from scratch. The Graphify-style `PreToolUse` hook pattern translates directly.

## Fit with Creek Vault and/or CrawDad

Creek-flavored sections:

| Graphify section | Creek `creek state` section | Source |
|---|---|---|
| Summary | Vault summary (fragment count, eddies, threads, frequency distribution, current wavelength snapshot) | All compiled-layer notes |
| Community Hubs | Active eddies (top N by fragment count) | `03-Eddies/` |
| God Nodes | Most-resonated fragments (high fan-out) | resonance graph |
| Surprising Connections | Synchronicities (cosine > 0.9, > 30 days, different sources) | `creek report --type synchronicity` output |
| Hyperedges | Praxis notes that span multiple eddies | `04-Praxis/` |
| Suggested Questions | 4–5 prompts the vault can uniquely answer right now | mining strategies × current phase |
| **(new)** Liminal Watch | Recently surfaced unnamed clusters, growing tag clusters, fresh paradoxes | `10-Liminal/` + Tag Garden |
| **(new)** Wavelength Snapshot | Current phase per recent fragments, dosage trends per frequency, detected phase transitions | `creek report --type wavelength` |
| **(new)** Pre-LLM Yield | Deterministic-pass classification yield, residue size | last `creek process` run |
| **(new)** Drift Warnings | Spec-vs-implementation drift (phase names, mode names), broken wiki-links, stale fragments | lint deterministic checks |

Output location: `00-Creek-Meta/State/<iso-week>.md` — weekly snapshot, with `00-Creek-Meta/State/latest.md` as a symlink/convenience copy.

## Translation if adapted

Two Creek-specific adaptations:

1. **Wavelength Snapshot is the most prominent section.** Graphify leads with "what's the structure of this corpus?" Creek leads with "where is the human on the wavelength right now?" — the phase context interprets every other section. A surprising synchronicity reads differently in a Bottoming Out phase than in a Peaking phase.
2. **Suggested Questions are wavelength-aware.** Don't suggest "what's a synthesis essay you should write?" during a Bottoming Out phase. The mining strategy `wavelength-phase-opportunity-windows` already encodes this; the audit report's suggested questions section should pull from it.

## Dependencies

- Depends on: ADOPT-001 (three-layer architecture — audit report describes the compiled layer).
- Pairs with: ADOPT-002 (lint output feeds several audit-report sections), ADOPT-006 (edge confidence tiers feed "surprising connections" ranking).

## Acceptance criteria

- A `creek state` CLI command produces `00-Creek-Meta/State/<iso-week>.md` with the sections listed above.
- The audit report can be re-rendered from the existing vault state without re-running any expensive pass — it's a *view*, not a pipeline.
- CrawDad's session-start (when implemented) reads `00-Creek-Meta/State/latest.md` before answering anything.
- The Wavelength Snapshot section appears first; structural sections (eddies, threads) appear under it.
- The Suggested Questions section is generated by the mining strategies filtered by the current wavelength phase.
- A regression test verifies the report has all required sections and no section is silently empty (empty sections render an explicit "no surfacing this week" note rather than missing).
