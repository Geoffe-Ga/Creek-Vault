## Epic Summary

Lay the data foundation for the Creek Writing Desk: a new top-level vault category
`11-Other-Authors/` that captures ideas the owner did **not** author (blogs, books, and
AI-as-user pieces), organized by author, with each work's *ideas* fully classified into the
ontology (frequency / wavelength / primitives) so they become navigable graph nodes — but
explicitly walled off from voice-proxy training so they never corrupt how the owner *sounds*.
Adds a two-axis attribution model (`voice_weight` + `representativeness`). Implements SPEC §7
and §9.

## Scope

**In scope:**
- New `11-Other-Authors/` scaffold subtree (template tree + `_README.md` + `_author.md` template) materialized by `creek init`.
- `AuthorManifest` Pydantic model + loader for `_author.md`.
- New `Fragment` frontmatter fields: `source.author_slug`, `voice_weight`, `representativeness` (backward-compatible defaults).
- Voice-corpus exclusion: `creek skills generate` excludes `11-Other-Authors/` (gate on `voice_weight > 0`); `ai-as-user` excluded by default.
- Classification of `11-Other-Authors/` content: ideas tagged with full ontology while `source.author` is set to `other`/`ai`; fail-closed `voice_weight=0.0` under the folder.

**Out of scope:**
- The writing desk / agents (EPIC_02).
- MCP/CrawDad surfacing (EPIC_03).
- Any medium contracts (EPIC_02/04).

## Success Criteria
