## Filing these as GitHub issues

The bodies contain `EPIC_0N_NUMBER` / `THIS_ISSUE_NUMBER` placeholders. File epics first, capture
their real numbers, substitute, then file children — finally edit each epic to add its child
checklist.

### Via `gh` CLI

```bash
cd plans/crawdad-writing-system/decomposition

gh label create "epic" --description "Tracks a workstream from a SPEC" --color "5319e7" 2>/dev/null || true
gh label create "spec-decomposition" --description "Filed from a SPEC decomposition" --color "0e8a16" 2>/dev/null || true

# 1. File each epic, capture its number (repeat for 02/03/04):
EPIC_01=$(gh issue create --title "epic: Vault category & attribution model" \
  --body-file EPIC_01_vault-attribution.md --label "epic,spec-decomposition,vault" \
  --json number --jq .number)

# 2. Substitute the real epic number into that epic's child bodies:
sed -i "s/EPIC_01_NUMBER/$EPIC_01/g" EPIC_01_ISSUE_*.md

# 3. File the children (titles are in each file's first heading / SPEC summary):
gh issue create --title "feat(vault): scaffold 11-Other-Authors/ category" \
  --body-file EPIC_01_ISSUE_01_scaffold.md --label "spec-decomposition,tracer-skeleton,vault"
# ... remaining children ...

# 4. Edit each epic body to fill in the Child Issues checklist with the real numbers, then:
gh issue edit "$EPIC_01" --body-file EPIC_01_vault-attribution.md
```
